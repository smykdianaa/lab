📌 Пояснення:

Файл poetry.lock фіксує точні версії всіх встановлених пакетів та їх залежностей. Це гарантує, що проект буде працювати однаково на будь-якому комп'ютері ("reproducible environment"), уникаючи конфліктів через оновлення бібліотек.

🔹 Основні команди ADK

create: створює нову структуру проекту для агента (файл коду, .env, ініціалізація).

run: запускає агента в інтерактивному режимі терміналу для тестування.

web: запускає локальний веб-сервер з графічним інтерфейсом для зручної взаємодії з агентами.

# Агент 1: my_first_agent

Було створено першого агента.

Що таке Agent клас?
Клас Agent — це основний "будівельний блок" у бібліотеці Google ADK. Його можна уявити як "мозок" твоєї програми. Він поєднує в собі:

Модель (LLM): Наприклад, gemini-2.5-flash, яка відповідає за розуміння мови.

Роль та інструкції: Через параметр instruction ти пояснюєш агенту, ким він є (математиком, вчителем чи розробником).

Можливості: Він вирішує, чи може він відповісти сам, чи йому потрібно скористатися стороннім інструментом (функцією) для отримання точних даних.

2. Для чого потрібен параметр tools?
Параметр tools — це список функцій, які агент може "викликати" за потреби.
Це критично важливо, тому що:

Точність: Великі мовні моделі часто помиляються в математиці або не знають поточних подій. Інструменти дозволяють ШІ використовувати реальний Python-код для отримання 100% точного результату.

Дії в реальному світі: Завдяки tools агент може не просто розмовляти, а й створювати файли, надсилати запити в інтернет або керувати вашим комп'ютером.

Функціональність: Коли агент бачить запит користувача, він порівнює його з описами функцій у списку tools і автоматично обирає потрібну.

3. Що робить функція get_current_time?
У контексті твоєї роботи ця функція є інструментом (tool). Її завдання:

Отримання даних: Вона використовує стандартну бібліотеку Python datetime, щоб дізнатися системний час сервера.

Структурування: Вона повертає дані у вигляді словника (dict), наприклад: {"time": "14:20:05"}.

Взаємодія: Агент отримує цей словник і "вплітає" отриманий час у свою відповідь українською мовою. Без цієї функції агент міг би вигадати час (галюцинувати), а з нею — він каже правду.

📌 Код:

from google.adk.agents.llm_agent import Agent

def get_current_time(city: str) -> dict:

    import datetime

    current_time = datetime.datetime.now().strftime("%H:%M:%S")

    return {"city": city, "time": current_time}

root_agent = Agent(

    model='gemini-2.5-flash',

    name='time_agent',

    instruction="Повідомляє час",

    tools=[get_current_time],

)

from google.adk.agents.llm_agent import Agent
from google.adk.tools.tool_context import ToolContext

def save_user_preference(tool_context: ToolContext, preference_type: str, value: str) -> dict:
    """Зберігає вподобання користувача в стані агента."""
    existing_state = tool_context.state.get(preference_type, [])
    # Оновлюємо стан
    tool_context.state[preference_type] = existing_state + [value]
    print(f"[Memory Added] {preference_type}: {value}")
    return {
        "status": "success",
        "message": f"Запам'ятав: {preference_type} - {value}"
    }

def recall_preference(tool_context: ToolContext, preference_type: str) -> dict:
    """Дістає вподобання зі стану агента."""
    preferences = tool_context.state.get(preference_type, [])
    if preferences:
        return {
            "status": "success",
            "values": preferences
        }
    return {"status": "error", "message": "Інформація відсутня"}

root_agent = Agent(
    model='gemini-2.5-flash',
    name='conversation_agent',
    description="Агент з довготривалою пам'яттю.",
    instruction="""
    Ти дружелюбний асистент. 
    Твоє завдання — знайомитися з користувачем та запам'ятовувати факти про нього.
    Коли користувач називає ім'я, хобі чи колір — викликай save_user_preference.
    Коли запитує про себе — викликай recall_preference.
    Відповідай українською мовою.
    """,
    tools=[save_user_preference, recall_preference],
)
